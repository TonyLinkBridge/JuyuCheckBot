# JUYU 域名体检｜隐私说明

更新日期：2026-08-27

## 保存的数据

- Telegram 数字用户 ID
- Telegram 公开用户名与显示名称（如有）
- 用户主动提交的域名与选择的使用意图
- 域名体检结果、来源标记和产品事件
- 报告生成时间、报告版本、资料来源和数据取得率
- 用户主动提交的购买、注册、出售或咨询资料
- 用户为了 JUYU 跟进而主动留下的联系方式

系统不会保存 Bot Token 或密码。没有进入商业提交流程的普通私人聊天内容不会保存；用户主动提交为 Lead 的需求和联系方式会保存并提供给 JUYU 管理员跟进。系统不会出售这些数据。

## 使用目的

数据用于生成及恢复报告、提供订阅解锁、处理用户主动提交的商业需求、联系用户、衡量产品转化、限制滥用和改进域名资料覆盖。

## 保留与删除

报告、产品事件和不活跃用户资料最多保留 180 天。用户可在 `@JuyuCheckBot` 发送 `/privacy`，选择“删除我的数据”，删除与其 Telegram 用户 ID 关联的报告、事件、未完成会话、新版 Lead 和用户资料。删除无法恢复。旧 `@JuyuDomainBot` 历史 Lead 暂时保存在旧系统中，需要通过 JUYU 联系管理员处理删除。

## 第三方处理

服务使用 Telegram、Vercel 与 Supabase 处理请求和保存数据，各服务可能依照其政策处理必要的技术信息。

公开版本由 Bot 服务的 `/privacy` 地址提供。`SUPABASE_SERVICE_ROLE_KEY` 只能保存在服务器环境变量中，绝不能发送给 Telegram 用户、浏览器或未来 Mini App。
