# JUYU 域名体检｜隐私说明

更新日期：2026-08-15

## 保存的数据

- Telegram 数字用户 ID
- Telegram 公开用户名与显示名称（如有）
- 用户主动提交的域名与选择的使用意图
- 域名体检结果、来源标记和产品事件
- 报告生成时间、报告版本、资料来源和数据取得率

系统不会保存 Bot Token、密码或其他私人聊天内容，也不会出售这些数据。

## 使用目的

数据用于生成及恢复报告、提供订阅解锁、衡量产品转化、限制滥用和改进域名资料覆盖。

## 保留与删除

报告、产品事件和不活跃用户资料最多保留 180 天。用户可在 `@JuyuCheckBot` 发送 `/privacy`，选择“删除我的数据”，删除与其 Telegram 用户 ID 关联的报告、事件和用户资料。删除无法恢复。

## 第三方处理

服务使用 Telegram、Vercel 与 Supabase 处理请求和保存数据，各服务可能依照其政策处理必要的技术信息。

公开版本由 Bot 服务的 `/privacy` 地址提供。`SUPABASE_SERVICE_ROLE_KEY` 只能保存在服务器环境变量中，绝不能发送给 Telegram 用户、浏览器或未来 Mini App。
