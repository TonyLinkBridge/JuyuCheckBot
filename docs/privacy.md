# JUYU 域名体检｜数据说明草案

当前未连接 Supabase 时，Bot 只在进程内临时保存体检报告约 30 分钟，进程重启后数据会消失。

启用 Supabase 后，计划保存：

- Telegram 数字用户 ID（不保存 Token、密码或私人聊天内容）
- 用户提交的域名、选择的使用意图和报告结果
- 来源标记与产品事件，例如 Preview、订阅 Gate 和报告解锁
- 报告生成时间、评分版本、置信度和数据覆盖率

用途包括生成报告、恢复历史报告、衡量产品转化和改进 JUYU Domain Score。正式启用持久化前，应补充公开隐私政策 URL、数据保留期限、删除请求入口和适用司法辖区说明。

`SUPABASE_SERVICE_ROLE_KEY` 只能保存在服务器环境变量中，绝不能发送给 Telegram 用户、浏览器或未来 Mini App。
